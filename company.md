# what we do
helps Python course students revise a little every day.
41 short lessons across 5 sessions, matched to the course.
each lesson: meaning, syntax, runnable example, exam trap, coding task, quiz.
code runs in the browser. no install, no login, free.
finished lessons come back for review before you forget them.

# proof we can claim
only our own numbers. none yet: say so.
no analytics, no accounts, so no user counts.
what we can say: 41 lessons, every task and quiz answer checked in real Python.

# alternatives
rereading class notebooks the night before the exam.
YouTube tutorials that don't match the syllabus.
big platforms (Codecademy, LeetCode) built for a different goal.
asking ChatGPT, which explains but doesn't make you practise.

# voice
short lines. no hype. no em dashes.
talk to one student, not "learners".
plain words first, then the Python term.
examples use real-feeling data: menus, prices, orders.
